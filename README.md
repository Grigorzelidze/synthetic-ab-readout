## Как посчитать заново

Нужны `psql`, Python 3.9+ и пакеты из `requirements.txt` (pandas, numpy, dbt). Локальный кластер — `127.0.0.1:54333`, каталог `.pgdata` в git не входит. В CI кластер не поднимается: workflow указывает на Postgres 16.

```bash
make build
make test
make check
```

`make build` заново генерирует CSV, грузит `raw.unit`, dbt собирает `clean.unit` и витрины, dbt-тест проверяет перекос, pandas сверяет счётчики и пишет README и страницу.

`make test` считает хи-квадрат на битом файле, подменяет загрузку и ждёт падения `dbt build`, затем возвращает чистый файл.

`make check` собирает README и страницу в памяти и сравнивает с файлами в git.

Сырой CSV в git не входит.
